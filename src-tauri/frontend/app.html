              How Sylvia stores keys and sends data
              
      Sylvia connects to services you already run or subscribe to; it does not download or start models.
                Campaign history stays on this computer, but messages and relevant campaign content, including Builder
                source material, are sent to the selected service. Remote services keep that data under their own
                privacy and retention terms; saving locally does not prevent the transmission.
      
              
      Saved API keys and private headers are protected by Windows for your user account. They are sent only to
                the selected service for authentication and are never put in chats or campaign backups. If Windows cannot
                unlock them, enter them again in Connection settings.
      
              
      This protects a settings file copied outside your Windows account. It does not protect against software
                running as your Windows user, or erase older plaintext copies of your settings.

      Use your ChatGPT subscription in Sylvia. You sign in through your browser; no API key is needed.

      Admin Full Audit
      
            
      Inspect exactly what Sylvia exchanges with models, for testing and debugging. Off unless you turn it on.
      
          
      
          
      
            Full Audit disabled · 0 safe mechanics diagnostics
            
      
              
              
              
            
      
          
      
          
      
            
      
              
      Always on · safe diagnostics
      
              
      Privacy-safe operation rejection diagnostics are always available. They hold only correlation IDs, the
                tool name, rejection code, field paths and whether state changed: no arguments, campaign prose, prompts or
                model reasoning.
      
            
      
            
      
              
      Full Audit · exact exchanges
      
              
      Direct connections capture the complete request sent to the model and the returned response chunks,
                including private reasoning and tool calls when available. ChatGPT subscriptions capture what Codex exposes; downstream model details
                may be unavailable. May contain spoilers.
      
            
      
          
      
          
      
            
      Developer diagnostics
      
            
      Search safe diagnostics and, when Full Audit is on, exact memory-only model exchanges. Credentials and
              authorization headers are never included. Exact traces disappear when Full Audit is disabled or Sylvia restarts.

      Local problem report
      
            
      
              
      Describe an app problem or give feedback on a model. You preview the exact file and save it yourself;
                nothing is uploaded, and Full Audit is not needed.
      
              
      
                
      
                  
                  
                
      
              
      
              
              
              
              
              
      
                What the report contains
                
      Small app diagnostics Sylvia keeps on this PC for up to seven days, within 1 MiB: action categories,
                  error codes, counts and timing. No chat, prompts, model replies, tool arguments, names or personal paths.
                  Campaigns and Full Audit records are not included. Add only details you want in the file.
