# Trigger Discipline

Private Obsidian vault for the modular modern / near-future tactical TTRPG ruleset.

## Open this first

**`Trigger Discipline.canvas`** is the human-facing visual rules atlas.

The Canvas maps are navigation only. The atomic Markdown notes they reference are the single canonical rules corpus.

`AGENTS.md` explains editing and layout conventions.

Implementation and generated-test entry points live under `Testing/`, including the balance-suite and Sylvia-package implementation documents. They are non-canonical engineering guidance.
