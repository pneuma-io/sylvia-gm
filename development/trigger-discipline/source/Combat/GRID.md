# GRID

**At a glance:** Tactical scenes use a grid by default so position, distance, LINE OF SIGHT, COVER, areas, and prepared zones share one consistent spatial model.

> [!note]- Full rules
> - The grid is the default representation for Trigger Discipline combat.
> - A lane is not a separate rules object. Hallways, streets, routes, and similar shapes emerge from map geometry.
> - Theater-of-the-mind play remains valid. In that mode, the GM or GM agent maintains an approximate grid-equivalent state behind the narration.
> - Before a player commits to a spatially consequential action in theater of mind, the GM should explain the inferred distance, exposure, COVER, and likely trigger consequences clearly enough for an informed choice.
> - Current maps use one-metre squares. Base movement costs are defined in [[MOVEMENT]]; scale and costs remain editable for future balance changes.
> - Align an ordinary one-cell prop's horizontal bounds to that cell. For example, a single Half-height crate occupies `[14,6,0]` to `[15,7,1.2]`; one continuous object owns its material, damage and destruction. Deliberate larger or offset objects remain valid.
> - A thin fence or wall can use physical clearance without reserving every cell it touches. Its actual thickness, endpoints and the actor's size still constrain movement and firing lines; a barrier does not extend automatically to the end of its neighboring cell.
