# NETWORK

**At a glance:** A graph of connected NODES and LINKS; its topology is mechanically meaningful.

> [!note]- Full rules
> LANs may contain multiple SEGMENTS and GATEWAYS. Internet access is not a magical property of every device: a NODE may only reach local peers, with wider connectivity appearing several hops away. Compromising one NODE gives a new position in the graph, not automatic ownership of everything connected.
>
> A concrete encounter NETWORK is durable authored repository/campaign data rather than an ephemeral graph created by an intrusion roll. Use stable NODE IDs and record LINKS, SEGMENTS, GATEWAYS, access routes, security barriers, privileges, monitoring, remote functions, and physical GRID bindings where a NODE represents a real device on the tactical map. Discovery/control state changes during play; the underlying authored topology changes only when something actually reconfigures, disconnects, destroys, adds, or removes it.
