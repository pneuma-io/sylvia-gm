# REMOTE FUNCTION

**At a glance:** A function a NODE actually exposes over the NETWORK, such as viewing a camera feed, rotating a camera, opening a door, or changing permitted configuration.

> [!note]- Full rules
> Reaching a NODE remotely does not grant capabilities the device does not expose. PRIVILEGE determines which exposed functions the current access may use.
