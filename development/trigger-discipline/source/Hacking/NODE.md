# NODE

**At a glance:** A discrete hackable device or system object: camera, workstation, door controller, router, server, turret, drone dock, terminal, or similar.

> [!note]- Full rules
> A NODE can expose remote functions, store local data/credentials/configuration, belong to a NETWORK SEGMENT, and connect to other NODES through LINKS. Direct LOCAL ACCESS can expose deeper device-level capabilities than normal network-facing access.
>
> When the NODE corresponds to a physical device, its network record uses a stable identity and binds to that device's GRID/map position. Destroying, disconnecting, moving, or reconfiguring the physical device changes the network state only as the real hardware and LINKS support.
