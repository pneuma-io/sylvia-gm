# STANDING ORDER

**At a glance:** Persistent autonomous instruction such as watch this doorway, follow me, observe this area, or return if damaged.

> [!note]- Full rules
> Issuing a new or materially changed order costs operator time/AP. Once established, the drone can continue executing the order without repeated AP spending.
