# GRENADE

**At a glance:** Thrown explosive/effect device resolved through a common physical sequence: PLACE -> WAIT/FUSE -> REACT -> DETONATE -> TRACE GEOMETRY -> RESOLVE EFFECT.

> [!note]- Full rules
> - PLACE: establish the grenade's actual landing point through GRENADE PLACEMENT.
> - WAIT/FUSE: track remaining tactical fuse time; cooking deliberately reduces that remaining time and carries the physical risk of holding an armed explosive.
> - REACT: threatened characters receive an EXPLOSIVE SAVE only when they have a real warning window and a physically possible defensive response.
> - DETONATE: the effect originates from the grenade's actual final position.
> - TRACE GEOMETRY: resolve distance, COVER, corners, material, and STANCE from that detonation point.
> - RESOLVE EFFECT: apply each EFFECT COMPONENT using its own physical profile.
> - Placement is the only throw CHECK. There is no second grenade ATTACK ROLL against every affected target after placement; legitimate defensive responses are handled by EXPLOSIVE SAVE before detonation.
> - An explosive/effect-device profile may contain multiple components such as FRAGMENTATION, BLAST / CONCUSSION, FLASH, or SMOKE. Components may use different geometry, target PENETRATION, MATERIAL PENETRATION, distance, posture, and persistence rules.
> - A component that must pass through external COVER uses MATERIAL PENETRATION / material interaction first. If the component then reaches a target, any target PENETRATION applies to RES separately.
> - Initial balance-suite reference families should include FRAGMENTATION, FLASH / CONCUSSION, and SMOKE grenades. Mines, directional charges, satchels, and specialized devices may be added later without changing the core grenade sequence.
> - Throwing a live grenade back is physically possible but is not required for the first balance-suite rules lock; it can be added later as a long-fuse interaction.
