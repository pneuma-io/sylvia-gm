# GRENADE PLACEMENT

**At a glance:** A thrown grenade targets an actual physical landing point. If placement is uncertain and meaningful, roll GRENADES; on failure the grenade still lands somewhere physically plausible rather than disappearing.

> [!note]- Full rules
> - Declare an actual GRID landing point or equivalent theater-of-mind location.
> - If placing the grenade there is trivial, no CHECK is required.
> - Otherwise use the normal CHECK structure: `1d20 + GRENADES + relevant APTITUDE + situational modifiers vs DIFFICULTY`.
> - PRECISION is the default benchmark APTITUDE for ordinary thrown-placement tests, but the normal relevant-APTITUDE rule still applies.
> - Difficulty can reflect distance, small openings, banking, throwing through windows or doors, awkward trajectories, movement, impairment, or other real constraints.
> - On success, the grenade lands at the declared point.
> - On failure, the grenade still follows a plausible physical path. Failure margin determines SCATTER DISTANCE and a randomized SCATTER DIRECTION around the intended point; walls, barriers, floors, openings, and other geometry constrain where it can actually end.
> - Explosion or effect always originates from the grenade's actual final position.
> - GRENADES expertise is separate from MARKSMANSHIP.

## Balance parameters
- throw AP
- placement DIFFICULTY bands
- SCATTER DISTANCE by failure margin
- any handling modifiers for particular grenade families
