# EXPLOSIVE SAVE

**At a glance:** If a threatened character has enough warning to attempt a real defensive response before detonation, the save determines whether that declared movement or stance change completes in time.

> [!note]- Full rules
> - EXPLOSIVE SAVE is a special explosive-resolution procedure, not a universal free-reaction system.
> - A threatened character receives a save only if they can perceive the grenade or receive timely warning, the remaining fuse leaves a meaningful response window, and some physical defensive response is actually possible.
> - An unnoticed grenade, an effectively no-warning detonation, or a sufficiently cooked grenade may allow no save.
> - Before rolling, declare the physical response: GET BEHIND COVER, GAIN DISTANCE, DIVE PRONE, or a combination that the warning window could realistically permit.
> - Use the normal CHECK structure. The benchmark fixture is `1d20 + ATHLETICS + relevant APTITUDE + situational modifiers vs EXPLOSIVE SAVE DIFFICULTY`; PRECISION is the ordinary benchmark APTITUDE for rapid body movement, but the normal relevant-APTITUDE rule still applies.
> - Difficulty reflects remaining warning time, distance required, current STANCE, obstacles, terrain, burden, and complexity of the declared response.
> - On success, complete the declared response before detonation and resolve the explosive from the character's new actual position and posture.
> - On failure, the response is not completed before detonation; resolve the explosive from the position and posture occupied when the response began.
> - EXPLOSIVE SAVE is not a generic save-for-half-damage rule. Its purpose is to determine whether the character physically beats the fuse.

## Balance parameters
- response-window thresholds
- maximum defensive movement available by warning time
- EXPLOSIVE SAVE DIFFICULTY modifiers
- any grenade-family-specific response restrictions
