# PROJECTILE

**At a glance:** A shot resolves against the first physical thing it intersects: FIRING SOLUTION → FIRST INTERSECTION → MATERIAL / TARGET → RES/HP.

> [!note]- Full rules
> - A successful ATTACK ROLL does not let a projectile skip intervening geometry.
> - If the first intersection is external material, resolve MATERIAL PENETRATION before anything behind it.
> - A material interaction can STOP the projectile, REDUCE its remaining offensive performance, or allow it to PENETRATE with comparatively little loss.
> - If a projectile continues, resolve the next physical intersection in order. Multiple barriers are therefore handled by repeating the same routing procedure rather than using a special multi-cover rule.
> - If the first valid intersection is the intended exposed target, or a projectile survives all intervening material and reaches the target, continue through the ordinary **target PENETRATION → RES / HP** pipeline.
> - MATERIAL PENETRATION through external objects and target PENETRATION through RES are distinct quantities. A projectile can lose one, the other, or both as material interactions dictate.
> - A character behind opaque full COVER can only be attacked through that material when the shooter has a plausible firing solution to the target's location. TARGET KNOWLEDGE such as CONFIRMED, LAST KNOWN, or APPROXIMATE provides only the positional precision its state actually contains.
> - Human bodies, ballistic shields, barriers, doors, furniture, and other physical objects use the same first-intersection logic. A controlled person between shooter and intended target is not an abstract defense bonus; the body is an intervening target if the projectile path actually crosses it.
> - Overpenetration exists where physically meaningful without tracking exact joules.
