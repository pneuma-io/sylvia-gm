## Read and modify the supplied source

Open COVERED-SOURCE.zip with any ZIP reader. No account, service request,
installation or execution is required to read the files. SOURCE-MAP.json records
each supplied file's exact length, SHA256, source pin and evidence scope.

selectors/selectors-0.36.1.crate is the complete pinned upstream tar/gzip source
archive. Extract it with a tar reader to obtain the package source, Cargo files
and build.rs. selectors/current-selected-source/ separately retains the sixteen
accepted selected source files. selectors/generated/ retains both byte-identical
1439-byte generated tables. Full MPL2.0 is in notices/MPL-2.0.txt; retain source
headers and notices when modifying or distributing covered material. The reviewed
parser/consumer and generated-input chain is documented, but optimized surviving
material and contemporaneous historical build source hashes remain unproven.
The package's build dependencies may require separate acquisition to compile;
this supplement does not claim a reproduced historical build.

certifi/cacert.pem is the exact 240216-byte pinned source copy already verified
in the retained work. Its original LICENSE, README and Makefile accompany it.
The Makefile documents the moving mkcert.org/generate/ service and subsequent
strip-non-ascii filter. pinned-tree.json records the fixed certifi source tree,
not a historical service response or Mozilla certdata revision. The pinned
repository remains available at:
https://github.com/certifi/python-certifi/tree/f4bc676bc101fe2235846e37044e8c693d6cbaf4
Do not run the moving endpoint and label its present response the historical
source. Whether the provided CA form and documentation satisfy all preferred
source-form requirements remains specifically qualified pending the historical
generator/Mozilla input investigation. No generation or trust-store changes run.
