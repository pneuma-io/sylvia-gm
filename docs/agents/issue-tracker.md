# Issue tracker: Dot Desk

Dot Desk (formerly Project Desk) holds current work items, scope, decisions and status. Update the
existing item rather than opening a competing tracker. GitHub holds project source and PRs.

When a skill says “fetch the relevant ticket”, read the linked Dot Desk item and its selected
requirements. When it says “publish to the issue tracker”, update that item with the result,
source/PR link, verification and remaining work. Creating work outside the current scope still
needs the owner's selection.

Checkout-local `.scratch/` records are historical or temporary evidence. They are not current
instructions, durable tickets or a second task system. Keep new scratch work inside the selected
work item's directory and remove it under the Pneuma IO Rulebook after delivery.
