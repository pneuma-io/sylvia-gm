# Siren Protocol extensions

## Current status

**No Siren Protocol-specific mechanical extension is required for the v0.1 authored profile.**

Trigger Discipline remains authoritative for generic mechanics. Siren Protocol's current playable implementation uses only permitted Campaign Setting operations: SELECT, RESKIN, INTERPRET, and CONSTRAIN.

See the [Ruleset Bridge](../docs/RULESET_BRIDGE.md) and [Playable Implementation](../docs/PLAYABLE_IMPLEMENTATION.md).

## v0.1 operations

### SELECT

Siren Protocol selects existing Trigger Discipline Classes, SKILLS, APTITUDES, SPECIALTY nodes, equipment families, and current reference-equipment tuning values for its authored implementation profile.

Selecting a current balance/test value into Siren Protocol v0.1 makes it an **implementation default**, not permanent setting-wide balance canon and not generic Trigger Discipline canon.

### RESKIN

The implementation gives existing equipment behavior Siren Protocol model identities such as PALISADE P15, R55, B12, M6/M7, CALYX Field Medical Kit, EMBERLINE Oriel, and other named 2225 products.

A reskin does not change underlying DAMAGE, PENETRATION, state, geometry, action economy, or equipment behavior unless an explicit setting rule separately says it does.

### INTERPRET

Siren Protocol cybernetics and future interfaces interact with existing Ruleset concepts through their actual capabilities:

- CivicLink can be a real identity/credential/payment/comms interface;
- DriveLink can be a real vehicle-control route;
- CommandMesh can be a real drone-control/sensor interface;
- multispectrum optics can provide real sensor modes;
- portable intrusion hardware can provide plausible NODE/LINK/interface access.

These interfaces do not invent privilege, links, sensor results, extra AP, automatic AIM, social bonuses, or physical functions the underlying systems do not possess.

### CONSTRAIN

The v0.1 profile deliberately does not fill several open mechanics with Siren Protocol-only guesses:

- armed drones are not part of the default catalog while the reference drones have no weapon/module and no weapon or attack profile is selected for these Setting drones;
- tactical vehicle combat is not added; VEHICLES checks plus normal spatial fiction handle current play;
- BURST/FULL AUTO physical modes remain real, but BURST/FULL AUTO use the contained Trigger Discipline implementation, without a second Setting formula;
- projected barriers exist through Trigger Discipline BARRIER/COVER logic, but Siren Protocol does not yet standardize their combat numbers;
- special ammunition remains possible but is not given a v0.1 tuning catalog;
- tube-fed loading and some general ready/stow handling remain physical states even where the current package requires GM judgment.

## Future extension gate

A future entry in this file must:

1. identify the exact Trigger Discipline mechanic or genuine gap;
2. state the Siren Protocol-only behavior;
3. explain why SELECT / RESKIN / INTERPRET / CONSTRAIN cannot solve the requirement;
4. define the real mechanical delta and interaction with existing rules;
5. cite the authored Siren Protocol setting source that requires it;
6. avoid inventing a parallel subsystem when Trigger Discipline already has a compatible concept.

Do not use this file merely to restate Trigger Discipline or to turn flavor into untracked bonuses.
