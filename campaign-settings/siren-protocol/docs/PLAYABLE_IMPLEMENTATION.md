# Siren Protocol implementation profile

This is an editable Setting profile below the world-fiction authority. It preserves eleven
authored Level-5 builds and their named equipment; a Plan may omit or rebuild any template.
It chooses no initial party, mission, protagonist or romance. Read `../SOURCE.md` for source
identity and package construction.

These are incomplete templates, not complete Character Files. Wan explicitly deferred the
starting/max HP, base/max RES, AP, complete ammunition/inventory and numerical progression
decisions on 2026-09-23. Do not fill those fields from TD conformance actors, benchmarks or UI
examples. Existing equipment values and cast choices are retained, not newly approved balance.

The cast's existing allocations are one skill at 5, one at 3, two at 2, one aptitude point and
five specialty choices. These describe these authored templates, not a universal original-character
budget or advancement rule. Blaze's GHOST/EVADER build expresses her on-foot skills; her VEHICLES
training governs driving. Siren's INFLUENCER/HANDLER build preserves her social/HUMINT role.

Mechanics belong to the contained TD snapshot. Read `references/character-authoring.md` and the
canonical class/specialty notes; [SOURCE.md](../SOURCE.md) explains the character-definition tools
available in contextual and general Builder chats. Validate class ownership,
choice budget, ENTRY, tier and keystone prerequisites independently of schema membership.
Save a complete Character File only after every required input has an explicit source.

Current TD has single, burst and automatic fire, chamber/feed/cycling/reload, recoil, physical
movement and cover, stance, prepared-fire and CQC paths. The selected package's actual tools,
`support/gameplay-resolution.json` and remaining admission findings determine support. Most
specialties still need GM adjudication; counterfactual test execution is not gameplay automation.
FOOTHOLD now has a network hook; Hex's existing choices are not automatically changed.

The Setting adds no second firearms or networking formula. Named equipment retains its authored
behavior and limitations. Nova's Oriel drones remain unarmed even where TD supports armed drones
with appropriate profiles. Projected-barrier numbers and special ammunition tuning remain unset.
Vehicles use VEHICLES checks and actual circumstances; this profile adds no vehicle-combat system.
Cybernetics supply real sensors, interfaces or control routes, not free AP, privileges or bonuses.

For between-encounter recovery, follow the contained TD notes. Genuine safety/time/support can
permit RES restoration; combat ending, gaining a level or reopening a campaign does not reset HP,
injuries, ammunition or other spent resources. Unspecified recovery amounts require adjudication.
