# Siren Protocol and Trigger Discipline

Trigger Discipline owns mechanics; Siren Protocol owns world fiction and explicitly selected
Setting values. A Plan owns its scenario, party and plot. Siren Protocol selects the year 2225;
TD itself remains suitable for other tactical eras. Do not promote this world's corporations,
technology or social assumptions into generic TD.

The format-4 Setting contains the exact TD snapshot supplied to the build. Its manifest and
`provenance/source-index.json` identify the actual bytes; an old branch name or source checkpoint
is not proof of compatibility. `../SOURCE.md` records the authored Setting origin and current
limits. No copy of TD is silently downloaded or replaced during construction.

Read the contained Ruleset's atomic references for classes, skills, aptitudes, specialties and
their prerequisites. Use its actual tool declarations and `support/gameplay-resolution.json`
for engine, hybrid, GM-adjudicated and unsupported boundaries. Test-only specialty tools are
excluded from ordinary package discovery. An allowed specialty ID alone grants no ability.

The existing cast and equipment under `../implementation/` remain editable templates.
Starting resources and numerical advancement are pending, so current template schema checks
must not be reported as complete character readiness. See [implementation guidance](PLAYABLE_IMPLEMENTATION.md).

Permitted Setting work can select an existing option, interpret a real interface, reskin a model,
or constrain its availability. An actual Setting-specific rules change must be explicit in
`../rules/HAREMRUN_EXTENSIONS.md` (the historical filename remains stable). A named drone, shield,
cybernetic implant or network does not acquire unprovided mechanics through descriptive text.

Preserve the eleven fiction anchors: Kora/BULWARK, Vesper/RIFLEMAN, Riot/BREACHER, Pixie/GHOST,
Sable/SHARPSHOOTER, Nova/TECH, Hex/HACKER, Solace/CORPSMAN, Velvet/INFLUENCER, Blaze/mobility and
Siren/social-HUMINT. The existing Blaze/GHOST and Siren/INFLUENCER builds are mechanical expressions,
not changes to their biographies. Full authored profiles remain under `../characters/`.
