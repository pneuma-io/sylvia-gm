# Siren Protocol Technology

Technology-specific Siren Protocol material lives here. Trigger Discipline remains authoritative for generic mechanics; these files define Siren Protocol's 2225 expression, named models, availability, and implementation defaults.

## Current v0.1 technology layer

- [Firearms, Protection, and Effects](FIREARMS_PROTECTION_AND_EFFECTS.md)
- [Medical, Drones, and Cybernetics](MEDICAL_DRONES_AND_CYBERNETICS.md)
- [Vehicles](VEHICLES.md)

Machine-readable authored values live in [`../../implementation/equipment.json`](../../implementation/equipment.json).

The v0.1 numbers explicitly select the current Trigger Discipline reference-equipment values as **implementation defaults**. They are not immutable setting-wide balance canon. Siren Protocol fiction can survive later numerical retuning.

## Design rule

Future technology should change real capabilities, interfaces, sensors, materials, access routes, or other defined Ruleset quantities. Do not turn the 2225 aesthetic into untracked magic bonuses.
