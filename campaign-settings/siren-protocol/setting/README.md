# Siren Protocol Setting

Focused setting canon and setting-specific technology guidance live under this directory.

## Sydney / Australia showcase

- [`locations/`](locations/) — Sydney coastal regional foundation, macro geography, and the complete initial 40-district playable layer.
- [`factions/`](factions/) — six principal oligarchies, eight recurring second-tier corporations, and named public, labour, community, advocacy, criminal, hacker, and grey-market powers.
- [`politics/AUSTRALIAN_CONCESSIONARY_OLIGARCHY.md`](politics/AUSTRALIAN_CONCESSIONARY_OLIGARCHY.md) — Australia's century-scale drift from Canberra-centred public authority toward patchwork concessionary oligarchy.
- [`technology/`](technology/) — Siren Protocol's 2225 named equipment/technology layer and the human-readable v0.1 implementation defaults for firearms, protection, effects, medicine, drones, cybernetics, and vehicles.

Machine-readable authored equipment values live under [`../implementation/`](../implementation/). Those balance/loadout selections are implementation defaults rather than immutable setting-wide canon.

The Sydney showcase is ready for further subdivision into neighbourhoods, individual sites, venues, encounters, and Campaign Plans. The Sydney region is not a mandatory campaign start.
